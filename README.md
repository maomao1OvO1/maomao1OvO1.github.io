## ✨ 功能亮点

**🤖 AI 余额一键查询**　主页查询盒支持 DeepSeek / Kimi / OpenAI，粘贴自己的 Key 就能查 —— **Key 不入库、不上传**，浏览器直连官方接口，带一键刷新与清除。

**🎮 小游戏大厅**　2048 · 贪吃蛇 · 打字 · 猜数字 · 五子棋 · 象棋 · 捕鱼 · 围棋，**全部接入排行榜**。

**🏆 排行榜（Firestore 云数据库）**　免费额度、永久保存、零冷启动；同名玩家自动覆盖。站长专属管理：增删改分数 · 删除某玩家全部记录 · **玩家汇总** · **呼吸灯名单**（授权谁上榜就亮彩色呼吸灯，站长本人改名也自动亮）· 用户管理。

**📱 硬件测试大厅**　免授权指纹检测 + 一键授权项目（17 项，按顺序逐个授权防崩溃）。

**👤 登录系统（Firebase）**　Google / GitHub / 邮箱 / 游客四门可用；支持绑定解绑三方账号、**邮箱+密码需先在邮件里点「确认」**、更改密码需旧密码验证。

**🎵 音乐 · 相册 · 💬 留言箱**　私藏的小角落；「联系我」需登录后发送，Firestore 直达站长后台（防滥用：蜜罐 / 限频 / 长度限制），**源码零邮箱**。

**🛡️ 反爬守卫 + 设备门禁**　评分制拦截自动化访问（放行搜索引擎爬虫）+ 首访弹一次适配提示，点「继续访问」即放行。

**🌙 深色模式**　黑色系设计（`#121212` / `#1e1e1e` / `#333`），主色紫 `#7C5CBF`。

## 🛠️ 技术栈

纯静态前端（**无框架**，原汁原味的 HTML / CSS / JS）：

| 组件 | 说明 |
|---|---|
| **Firebase Auth** | Google / GitHub / 邮箱密码登录（弹窗版 OAuth） |
| **Firebase Firestore** | 排行榜 `scores`（公开读写、**仅站长可删**）· `special`（呼吸灯名单）· `contact_messages`（留言箱） |
| **Service Worker** | 离线缓存（更新时带 `?v=N` 破缓存） |
| **Node.js（开发用）** | `tokens-server.js` 本地静态托管预览（端口 3001） |
| **小后端** | `maomao-admin-api`：仅供站长查看用户注册 / 登录时间的独立 API |

## 🚀 本地运行

```bash
# 网站预览（端口 3001，带登录逻辑）
PORT=3001 node tokens-server.js        # → http://localhost:3001

# 纯静态预览（端口 3000，无登录逻辑）
python3 -m http.server 3000 --bind 127.0.0.1   # → http://127.0.0.1:3000
```

## 🔐 登录与安全

- **游客**默认可浏览；登录后可绑定 / 解绑 Google、GitHub、邮箱。
- 邮箱验证邮件如果没看到，记得瞄一眼**垃圾箱**。
- 「更改密码」必须输入当前密码（Firebase reauthenticate）—— 防止别人拿到会话就改密。
- **联系方式 = 留言箱**：登录后发送，Firestore 直达站长后台；**源码已零邮箱**（明文 / 密文 / 密钥全部移除），爬虫扒源码也挖不到。
- **站长后台**（排行榜管理 / 玩家汇总 / 呼吸灯名单 / 访客留言）只有站长账号能用，写入与删除都经 Firebase 规则 `isOwner` 校验。
- 🔒 **隐私红线**：AI Key 只在你自己的浏览器里直连官方接口，**后端与仓库永不落库**；测试数据绝不进排行榜与仓库。
