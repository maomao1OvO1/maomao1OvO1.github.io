## 这是什么


一个安卓单机塔防游戏《共鸣之塔》的**完整源码**。玩法核心是原创的「元素共鸣」：
相邻摆放不同元素的塔会触发组合技（合计 91 种），同元素相邻则是「共振」。

- **纯 HTML5 + Canvas** 实现，无框架、无第三方库、无联网
- 源码**按模块拆分**在 `src/`：HTML 骨架 + 3 个 CSS + 21 个 JS（每个文件开头都写清了它负责什么）
- 附带构建脚本 `src/build.js`，能把 `src/` 拼回**单文件** `game.html`
- 安卓壳只是 WebView 容器，真正的游戏就是这套源码
- 无联网、无内购、无广告、无统计埋点

## 拿到源码怎么玩

### 方式一：直接用浏览器跑（推荐，零门槛）

两种都行，看你习惯：

| 用哪个 | 适合 | 说明 |
|---|---|---|
| `src/index.html` | **改代码** | 多文件版，改哪个文件刷新就见效，不用构建 |
| `game.html` | **只想玩/一键拿走** | 单文件版，双击就能跑，也是测试与 APK 用的那份 |

> 🎵 **网页版没有背景音乐，是正常的**：BGM 文件 4.4MB，**只打进 APK**（包内 `assets/music/bgm.ogg`），没有放进仓库（免得仓库无谓变大）。想让网页版也有音乐：从 APK 里把 `assets/music/bgm.ogg` 拷到本目录的 `music/` 下即可 —— `index.html` 里 `<audio src="music/bgm.ogg">` 已经在等它了。

> 建议用 Chrome，按 F12 打开控制台 —— 报错会直接显示，改起来快得多。

### 方式二：改完源码，拼回单文件

```bash
node src/build.js          # 把 src/ 拼回 ../game.html
```

**规矩只有一条：`src/` 是唯一源码，`game.html` 是构建产物。**
要改游戏就改 `src/`，改完跑一次 build；不要直接编辑 `game.html`（下次构建会被覆盖）。
拆分时做过无损校验：用 `src/` 拼回去的结果与拆分前的单文件**字节级完全一致**。

### 方式三：装成安卓 APK
见 `../docs/modding.md` 里「想打包成自己的 APK」一节（需要 aapt2 / javac / d8 / apksigner）。
打包出来的包用**你自己的签名**即可，不需要和任何人一致。

### 方式四：直接改网上那个 APK
把 APK 后缀改成 `.zip` 解开，`assets/` 里就是源码 —— **已按模块拆开**：`index.html` + `css/`(3) + `js/`(21)，与仓库里的 `src/` 完全一致（v8.20 起已移除全部加固，包内就是明文，可直接改）。

## 数据都在哪（改游戏从这里下手）

游戏是**数据驱动**的，几乎所有内容都集中在几个对象字面量里，搜关键字就能定位：

| 想改什么 | 搜索 | 在哪个文件 |
|---|---|---|
| 9 座塔（造价 / 伤害 / 攻速 / 射程 / 特性 / 专属成长） | `var ELEMS = {` | `js/04-towers.js` |
| 每座塔的专属成长 | `var TOWER_GROWTH` / 升级段 | `js/06-upgrades.js` |
| 76 张强化卡 | `var BUFF_POOL = [` | `js/05-cards.js` |
| 敌人（血量 / 速度 / 金币 / 特性） | `var ENEMIES = {` | `js/07-enemies.js` |
| 15 个关卡（波数 / 初始金币 / 难度 / 路径） | `var LEVELS = [` | `js/04-towers.js` |
| 6 种天气 | `var WEATHERS = {` | `js/10-waves.js` |
| 4 个主动技能 | `var SKILLS = [` | `js/04-towers.js` |
| 8 个元素套装 | `var ELEM_SETS = {` | `js/04-towers.js` |
| 14 个成就 | `var ACHIEVEMENTS = [` | `js/04-towers.js` |

> **加一座塔只需要加一条数据** —— 建塔面板、图鉴、升级面板都是遍历 `ELEMS` 生成的，会自动收录。
> 第 9 座塔「🔫 机枪」就是这么加的，可以当模板看。

完整的改造教程（含 8 个照着抄的例子）见 **[../docs/modding.md](../docs/modding.md)**。

## 跑测试（改完建议跑一遍）

仓库自带 **59 套自动化测试**，用 Node 跑，不需要浏览器 —— 它把游戏代码抽出来塞进一个假 DOM 里模拟运行：

```bash
node test/deep4.js game.html          # 单跑一套（deep4 = 完整通关）
for t in test/*.js; do node "$t" game.html | tail -1; done   # 跑全套
```

> 测试读的是**单文件** `game.html`，所以改完 `src/` 记得先 `node src/build.js`。

其中 `test/audit_fuzz.js` 值得单独说：它会做**静态体检**（僵尸字段、词缀与套装是否真接入、
HTML 重复 id、引用不存在的元素）＋ **4000 次随机操作 fuzz**（随机建塔/开面板/乱点按钮/放技能/切美术/结算/跑帧），
并持续校验状态一致性与数值越界。改完之后跑它很容易发现自己漏了什么。
